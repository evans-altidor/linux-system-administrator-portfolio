# linux-system-administrator-portfolio
Hands-on Linux administration labs, Bash automation, networking, security, and troubleshooting projects.
## About Me

I am an aspiring Linux System Administrator building practical skills through hands-on labs and documented technical projects.

My training focuses on Linux system administration, user and group management, file permissions, networking, security, Bash scripting, backups, monitoring, and troubleshooting.

## Technical Skills

- **Operating Systems:** Ubuntu Server Linux
- **Command Line:** Bash, filesystem navigation, file management
- **System Administration:** Users, groups, permissions, sudo, services, processes
- **Networking:** IP addressing, DNS basics, connectivity troubleshooting, SSH
- **Security:** Least privilege, access control, updates, secure configuration
- **Automation:** Bash scripting and scheduled tasks
- **Monitoring:** System resources, logs, service health
- **Version Control:** Git and GitHub

*Skills are being developed and demonstrated through the projects below.*
