# Linux Fundamentals Lab

## Objective

Practice essential Linux commands and understand the Linux filesystem.

## Environment

- Ubuntu Server LTS
- VirtualBox virtual machine
- Non-production training environment

## Tasks Completed

- Identified the current user and hostname.
- Inspected the Linux distribution and kernel.
- Navigated directories.
- Created, copied, and renamed files.
- Searched file contents with grep.
- Inspected disk space and memory usage.

## Commands Practiced

| Command | Purpose |
|---|---|
| `whoami` | Show the current user |
| `pwd` | Print the current directory |
| `ls -la` | List files, including hidden files |
| `cat /etc/os-release` | Identify the Linux distribution |
| `df -h` | Inspect filesystem capacity |
| `free -h` | Inspect memory usage |
| `grep "Linux" notes.txt` | Search for matching text |

## Verification

I ran each command in my Ubuntu Server virtual machine and reviewed its output.
